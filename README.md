# Object Detection Projects

A collection of computer vision and object detection projects built using Python, YOLOv8, OpenCV and CVZone.

This repository documents my learning journey in computer vision, starting with basic YOLO object detection and progressing towards practical real-world applications.

## Technologies Used

- Python
- YOLOv8 (Ultralytics)
- OpenCV
- CVZone

**Status:** In Progress

### 2. Basic YOLO Detection
Exploring object detection using pretrained YOLOv8 models on images, videos and webcam feeds.

## Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/TheRealKushagra/Object-Detection-Projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Object-Detection-Projects
   ```

3. Create and activate a virtual environment.

4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Download the required YOLO model weights separately and place them in the appropriate directory.
